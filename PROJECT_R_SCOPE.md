# Проект Р: область frontend-прототипа

## Источник требований

Основной состав работ проекта Р:

`/home/user/BA_LandochkinaA/Залоговый модуль Р/Экспресс-оценка Залоги Р______ 02062026 выжимка для ИИ без Развития.xlsx`

Проект S используется только как референс и исходная проверенная база frontend-прототипа.

## Границы текущего этапа

- Создается только frontend-прототип.
- ТЗ и документы для заказчика будут готовиться отдельно позднее.
- Папка проекта S не изменяется.
- Изменения выполняются только в копии прототипа внутри проекта Р.

## Адаптация под проект Р

- Добавлен реестр страховых полисов.
- Добавлены экраны источников задач, интеграций и миграции.
- Расширен справочник типов задач по формулировкам состава работ Р.
- Добавлены сценарии email, конвейеров, расписания, триггеров и Excel-импорта.
- Добавлены демо-данные по печатным формам и миграционным партиям.
- Валюта прототипа приведена к российскому рублю: RUB / ₽.
- Внешние источники и интеграции ограничены составом работ Р; узбекские источники не используются.
- Сохранены проверенные алгоритмы S: осмотр, оценка, документы, страхование, кросс-залоги, LTV и мобильные сценарии.

## Общие компоненты

Единый вид компонента нужно сохранять во всех местах использования:

- Документы.
- Фото снимки объекта залога.
- Информация о клиенте и договоре.
- Информация по объектам залога.
- Основная информация по задаче.
- Экспертное заключение.
- История действий по задаче.
- Описание объекта залога.
- Страхование.
- Настройки мониторинга.
