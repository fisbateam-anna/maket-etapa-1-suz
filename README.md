# Макет Этапа 1 СУЗ

## Запуск

```bash
cd "<рабочая папка макета>"
python3 -m http.server 5185
```

Открыть в браузере:

```text
http://127.0.0.1:5185/
```

Если порт занят, используйте соседний порт, например:

```bash
python3 -m http.server 5186
```

В текущей проверке интерактивный макет запущен на:

```text
http://127.0.0.1:5185/
```

## Что реализовано

- Самодостаточный frontend-only интерактивный макет без backend и внешних сервисов.
- Ролевая навигация и переключатель ролей.
- Реестры задач, договоров, залогов и страховых полисов с фильтрами, KPI и интерактивными диаграммами.
- Карточка задачи с действиями: сохранить, отложить, вернуть, завершить, переназначить, передать в АБС.
- Карточка договора с участниками сделки, связанными залогами и показателями покрытия.
- Карточка залога с вкладками: общая информация, мониторинг, оценки, страхование, договоры и обременения, залогодатели, риски, внешние данные, документы.
- Создание задачи вручную с выбором типа, объекта, исполнителя, срока и документов.
- Имитация импорта Excel с протоколом корректных, обновляемых и ошибочных строк.
- Отдельные экраны: источники задач, интеграции, миграция договоров залога.
- Типы задач по составу работ проекта Р: документарные/физические осмотры и мониторинги, единичная/списочная переоценка, отчетность, операции с залогом.
- Отчеты руководителя и печатные формы.
- Мобильные сценарии для выездного сотрудника и клиента.

## Роли

- Специалист залогового подразделения: задачи, договоры, залоги, импорт, создание задач, редактирование разрешенных полей.
- Руководитель подразделения: все задачи подразделения, переназначение, отчеты, аналитика.
- Выездной сотрудник Банка: только мобильные задачи осмотра и фотофиксация.
- Клиент: только активный дистанционный запрос Банка и фотофиксация.
- Администратор/методолог: контроль данных, риск-параметры и роли без отдельного пользовательского раздела логов.

## Имитированные интеграции

- Почтовый сервер, конвейеры, Excel-импорт, расписание и триггеры: создание задач.
- АБС, ЕСМ Банка, система распознавания документов: внутренние обмены.
- Авито, Авто.ру, Яндекс Недвижимость, Циан, ЕГРН, SpectrumData, Мобильный оценщик, Инфосфера: оценка и внешние проверки.

## Технические ограничения

Макет реализован без Vite/React-зависимостей и запускается как статический frontend. Код разложен по `src/data.js`, `src/app.js`, `src/styles.css` и может быть перенесен в React/Vite без изменения продуктовой структуры экранов.
